# Delta: transaction-form

## ADDED Requirements

### Requirement: 编辑表单回显分录账户
编辑模式打开交易表单时，系统 SHALL 用分录的 `account_id` 初始化每条分录的账户选择器，使已有账户正确回显，且用户不重新点选账户即可通过提交校验直接保存。

#### Scenario: 打开编辑表单账户已选中
- **WHEN** 用户编辑一笔各分录均已有账户的交易
- **THEN** 每条分录的账户选择器显示其账户，而非"选择账户"占位符

#### Scenario: 直接保存编辑表单
- **WHEN** 用户打开编辑表单后未改动分录账户，直接提交
- **THEN** 提交校验通过，交易按原账户保存成功

#### Scenario: 修改账户时定位到当前账户
- **WHEN** 用户点击已有账户的分录账户选择器
- **THEN** 账户选择面板打开时已选中当前账户，且其祖先链已展开、当前账户可见
