# Spec Delta

## MODIFIED Requirements

### Requirement: 抽屉式编辑面板
系统 SHALL 在选中账户时从页面底部拉起抽屉，显示账户详情和 inline 编辑控件。

#### Scenario: 抽屉显示账户信息
- **WHEN** 用户选中一个账户
- **THEN** 抽屉显示账户名称、账单日、还款日、所有者、关闭状态

#### Scenario: 编辑账户名称
- **WHEN** 用户在抽屉中修改账户名称并确认
- **THEN** 系统调用 rename API 更新账户名称

#### Scenario: 编辑账单日和还款日
- **WHEN** 用户在抽屉中修改账单日或还款日并确认
- **THEN** 系统更新对应字段

#### Scenario: 编辑账户所有者
- **WHEN** 用户在抽屉中修改账户所有者并确认
- **THEN** 系统调用 set_owner API 更新所有者

#### Scenario: 关闭账户
- **WHEN** 用户在抽屉中点击关闭账户
- **THEN** 系统调用 close API 关闭账户，卡片显示关闭状态

#### Scenario: 重开账户
- **WHEN** 用户在抽屉中对已关闭账户点击重开
- **THEN** 系统调用 open API 重开账户

#### Scenario: 删除账户
- **WHEN** 用户在抽屉中点击删除账户
- **THEN** 系统先弹出确认弹窗，确认后调用 delete API 删除账户（根账户和系统账户不显示删除入口）

#### Scenario: 删除有子账户的账户确认级联范围
- **WHEN** 用户点击删除一个有子账户的后代账户并触发确认弹窗
- **THEN** 确认文案体现级联范围（如「删除〈某账户〉及其 N 个子账户？」，N 为该账户的后代总数），让用户知晓将整树删除

#### Scenario: 删除失败弹窗提示
- **WHEN** 删除 API 返回错误（如账户或其后代仍被引用）
- **THEN** 系统以弹窗显示后端返回的失败原因，账户保留在列表中，抽屉保持打开

#### Scenario: 删除成功后更新列表
- **WHEN** 删除 API 返回成功
- **THEN** 该账户及其子树从账户列表中移除，抽屉关闭，选中态清除

#### Scenario: 根账户不可编辑
- **WHEN** 用户选中的是根账户
- **THEN** 抽屉中不显示编辑控件，只显示账户信息
