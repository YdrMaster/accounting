# beancount-import（增量）

## ADDED Requirements

### Requirement: 导入原子性

导入的写库阶段 SHALL 在单个数据库事务中执行：任一写库操作失败时，系统 MUST 回滚本次导入已执行的全部写入，不残留部分数据，并以错误终止导入。解析期错误（格式无法识别、`member` metadata 缺失或未知）的既有「报错并终止导入」语义不变；附件文件读取失败的既有「警告并继续」语义不变。

#### Scenario: 执行期失败零残留

- **WHEN** 导入过程中任一写库操作返回错误（如约束冲突）
- **THEN** 本次导入已执行的全部写入被回滚，数据库不残留任何部分数据，系统以非零状态报错

#### Scenario: 导入成功整体提交

- **WHEN** 导入的全部写库操作均成功
- **THEN** 系统在单个事务中提交，商品、账户、成员、渠道、交易、附件要么全部可见要么全部不可见

#### Scenario: 附件读取失败不阻断

- **WHEN** `document` 指令引用的附件文件不存在
- **THEN** 系统输出警告并继续导入，其余数据正常提交
