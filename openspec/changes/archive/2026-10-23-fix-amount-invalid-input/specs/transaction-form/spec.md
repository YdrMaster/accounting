# Spec Delta

## ADDED Requirements

### Requirement: 金额输入合法性
分录金额为文本输入框，允许用户输入过程中保留不完整文本（如 `-`、`.`、`-.`）。系统 SHALL 将非空且不符合金额格式（可选前导负号、至多一个小数点、至少一位数字）的文本判定为非法，并让该输入框显示错误态（红色轮廓）。非法文本 MUST NOT 导致页面渲染或交互崩溃，且 MUST NOT 被视为「已填写」金额。

#### Scenario: 单独输入负号不崩溃
- **WHEN** 用户清空某分录金额框后只输入 `-`
- **THEN** 表单保持正常渲染，该输入框显示红色轮廓，页面不白屏

#### Scenario: 其他非法中间态不崩溃
- **WHEN** 用户输入 `.` 或 `-.` 等非法文本
- **THEN** 文本保留在输入框中并显示红色轮廓，表单不崩溃

#### Scenario: 非法金额不算已填写
- **WHEN** 某分录金额框内容非法（如 `-`）
- **THEN** 该分录不被视为金额已填写，确认按钮与「添加分录」按钮均置灰禁用

#### Scenario: 合法金额不标红
- **WHEN** 用户输入 `-5`、`10.`、`.5` 或 `0`
- **THEN** 输入框不显示错误态

#### Scenario: 清空不算非法
- **WHEN** 用户清空某分录金额框
- **THEN** 输入框不显示错误态（视为未填写）

## MODIFIED Requirements

### Requirement: 借贷平衡校验
提交按钮 SHALL 仅在同时满足以下条件时可用：所有分录金额非空且合法、至少两笔有效分录、日期时间与成员已填写、所有分录金额之和为零；任一条件不满足时确认按钮 SHALL 置灰禁用。

#### Scenario: 不平衡时禁用
- **WHEN** 分录金额之和不为 0
- **THEN** 确认按钮置灰禁用，不显示额外提示文字

#### Scenario: 平衡时可提交
- **WHEN** 分录金额之和为 0，所有金额非空且合法，日期时间与成员已填，且至少有两条有效分录
- **THEN** 确认按钮可用

#### Scenario: 存在非法金额时禁用
- **WHEN** 任一分录金额框内容非法（如 `-`）
- **THEN** 确认按钮置灰禁用

#### Scenario: 存在未填金额时禁用
- **WHEN** 任一分录金额框为空
- **THEN** 确认按钮置灰禁用
