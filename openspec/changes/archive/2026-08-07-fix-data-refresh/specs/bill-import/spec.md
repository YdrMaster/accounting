# Spec Delta: bill-import

## ADDED Requirements

### Requirement: 导入成功后前端数据刷新

通过 Web 设置面板导入账单文件成功后，前端 SHALL 失效并重新加载所有受导入影响的展示数据，MUST 至少包括：交易列表、日历日统计、月度汇总、账户余额、资产负债表/收支报表、预算状态与攒钱计划状态。仅弹出导入结果提示而不刷新数据是不满足本需求的。

#### Scenario: 导入账单后各视图数据更新

- **WHEN** 用户在 ConfigPanel 选择一个账单文件并成功导入
- **THEN** 除展示导入结果（成功/跳过/失败数量）外，交易列表、账户、报表、预算与攒钱计划的数据缓存被失效，切换到对应视图时展示导入后的最新数据

#### Scenario: 导入部分失败仍刷新

- **WHEN** 导入按 skip-on-error 策略完成且存在跳过/失败的条目
- **THEN** 已成功导入的条目对应的数据仍被刷新到各视图，导入结果提示如实展示成功与失败数量
