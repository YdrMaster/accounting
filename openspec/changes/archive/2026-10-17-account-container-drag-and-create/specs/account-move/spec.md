# Spec Delta

## MODIFIED Requirements

### Requirement: 移动校验
系统在移动账户前 MUST 按序校验：被移动账户存在且非根账户、非系统账户；目标父账户存在；目标父账户不是被移动账户自身或其后代（防成环）；目标父账户下无同名账户。校验失败 MUST 返回明确错误且不修改任何数据：HTTP 层 SHALL 返回 4xx/5xx 状态码与本地化错误文案，SHALL NOT 以 2xx 状态返回错误信息；同级重名失败 SHALL 明确报出目标父账户下已存在同名子账户及冲突账户名。

#### Scenario: 根账户不可移动
- **WHEN** 被移动账户是根账户（无父账户）
- **THEN** 请求被拒绝并返回错误

#### Scenario: 系统账户不可移动
- **WHEN** 被移动账户 `is_system` 为真
- **THEN** 请求被拒绝并返回错误

#### Scenario: 目标父账户不存在
- **WHEN** 请求中的 `parent_id` 不存在
- **THEN** 请求被拒绝并返回错误

#### Scenario: 防止成环
- **WHEN** 目标父账户是被移动账户自身，或位于被移动账户的子树内
- **THEN** 请求被拒绝并返回错误

#### Scenario: 同级重名
- **WHEN** 目标父账户下已存在同名账户
- **THEN** 请求被拒绝并返回错误

#### Scenario: 同级重名错误明确可读
- **WHEN** 目标父账户下已存在同名账户导致移动被拒绝
- **THEN** 响应携带 4xx 状态码（如 409）与本地化文案，明确指出目标父账户下已存在同名子账户，文案中包含冲突账户名

#### Scenario: 错误不伪装为成功
- **WHEN** 移动因任一校验失败被拒绝
- **THEN** HTTP 响应状态码 MUST 为 4xx 或 5xx，客户端依据状态码即可判定失败，响应体不是被序列化为 200 的错误文本
