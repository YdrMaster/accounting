# account-delete

## Purpose

账户删除服务能力——`DELETE /api/accounts/{id}` 端点对目标账户及其整棵子树执行引用检查与级联删除：子树内所有账户均未被引用时一次请求删除整棵子树，任一账户被引用时以明确的本地化文案与 4xx 状态码拒绝，并指名挡路的账户与引用来源。

## Requirements

### Requirement: 删除账户 API
系统 SHALL 提供 `DELETE /api/accounts/{id}` 端点，删除目标账户及其整棵子树（含各级后代）。子树引用检查与子树删除 MUST 在同一事务内完成，任一步失败整体回滚，SHALL NOT 留下部分删除的状态。删除成功后，被删子树的账户行、闭包表行（`account_ancestors`）与所有者关联（`account_owners`） SHALL 一并清除。

#### Scenario: 删除无引用的叶子账户
- **WHEN** 客户端请求删除一个自身未被任何引用占用的叶子账户
- **THEN** 该账户被删除，其闭包表行与所有者关联一并清除，返回成功响应

#### Scenario: 级联删除干净子树
- **WHEN** 客户端请求删除一个有子孙账户的账户，且其子树内所有账户均未被任何引用占用
- **THEN** 整棵子树（目标及各级后代）在一次请求内被全部删除，返回成功响应

#### Scenario: 校验失败不留部分删除
- **WHEN** 删除请求因子树内引用检查未通过而失败
- **THEN** 数据库中不发生任何删除，目标账户及其子树保持原状

### Requirement: 子树引用检查
系统在删除前 MUST 校验：目标账户存在、非系统账户；目标账户及其子树内任一账户未被以下任一引用占用——分录（`postings`）、账户映射（`account_mappings`）、预算限额（`budget_limits`）、攒钱计划账户（`saving_plan_accounts`）、渠道（`channels`）。检查范围 SHALL 为经闭包表确定的整棵子树，而非仅目标账户本身；子树内任一账户命中任一引用 SHALL 整体拒绝删除。

#### Scenario: 账户自身被分录引用
- **WHEN** 客户端请求删除一个自身存在关联分录的账户
- **THEN** 删除被拒绝，文案说明该账户有关联分录

#### Scenario: 后代被引用时整体拒绝
- **WHEN** 客户端请求删除一个有子孙的账户，其自身与直接子账户均无引用，但某个更深层后代存在关联分录或映射
- **THEN** 整棵子树的删除被拒绝，文案指名该后代账户

#### Scenario: 五类引用来源逐一拦截
- **WHEN** 被删子树内任一账户被预算限额、攒钱计划账户或渠道引用（即使无分录、无映射）
- **THEN** 删除被拒绝，文案说明引用来源为预算、攒钱计划或渠道

#### Scenario: 子树全部干净时允许级联
- **WHEN** 被删子树内所有账户（含目标自身）均无上述任何引用
- **THEN** 子树检查通过，按删除账户 API 语义级联删除整棵子树

### Requirement: 删除错误契约
删除校验失败 MUST 返回明确的 HTTP 4xx/5xx 状态码与本地化错误文案（按请求语言），SHALL NOT 以 2xx 状态返回错误信息。因子树内引用被拒时，文案 SHALL 指名挡路账户的显示名与引用来源（如「子账户〈外卖〉有关联分录，不能删除」）；账户不存在 SHALL 返回 404 语义，系统账户（含根账户）不可删除 SHALL 返回 4xx 并说明原因。

#### Scenario: 错误不伪装为成功
- **WHEN** 删除因任一校验失败被拒绝
- **THEN** HTTP 响应状态码 MUST 为 4xx 或 5xx，客户端依据状态码即可判定失败，响应体不是被序列化为 200 的错误文本

#### Scenario: 指名挡路的后代账户
- **WHEN** 删除因子树内某个后代账户被引用而拒绝
- **THEN** 错误文案包含该后代账户在请求语言下的显示名及其引用来源

#### Scenario: 区分引用来源的文案
- **WHEN** 删除被拒绝且挡路引用分别为分录、账户映射、预算限额、攒钱计划账户或渠道
- **THEN** 文案分别说明对应的引用来源，提示用户先处理相应引用

#### Scenario: 账户不存在
- **WHEN** 客户端请求删除一个不存在的账户 ID
- **THEN** 返回 404 状态码与本地化错误文案

#### Scenario: 系统账户不可删除
- **WHEN** 客户端请求删除 `is_system` 为真的账户（含四个根账户）
- **THEN** 删除被拒绝，返回 4xx 状态码与「系统账户不能删除」文案
